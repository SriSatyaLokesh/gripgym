# GripGym

## What This Is

GripGym is a static gym/fitness website built with plain HTML, CSS, and JavaScript. The project is a full rebrand and visual redesign of an existing generic "Fitness Club" template — replacing all placeholder content with real GripGym copy, establishing a dark & bold brand identity, and adding a new Gallery section.

## Core Value

A visually striking, dark-themed gym website that authentically represents the GripGym brand and compels visitors to join.

## Business Context

- **Customer**: Gym members and prospective members
- **Revenue model**: Drives membership sign-ups and class bookings via contact/CTAs
- **Success metric**: Visitors can immediately identify GripGym's brand and navigate to key info (classes, pricing, contact)
- **Strategy notes**: Phase 1 milestone is a polished v1 website; no backend/booking system in scope

## Context

- **Brownfield**: Existing single-page HTML/CSS/JS site with 9 sections
- **Current state**: Generic template with Lorem Ipsum placeholder content throughout
- **No build tools**: Plain files — no npm, no bundler, no preprocessor
- **Animations**: WOW.js + Animate.css (retain and enhance)
- **Font Awesome**: Already referenced for icons (retain)
- **Images**: Existing images in `/images/` — user will supply real photos per section

## Constraints

- **Tech stack**: HTML5 / CSS3 / vanilla JS only — no frameworks, no build tools
- **Design**: Dark & bold — intense, athletic, motivational aesthetic throughout
- **Content**: Real copy supplied by user per phase; no Lorem Ipsum in final deliverable
- **Scope**: Visual rebrand + Gallery section only — no backend, no CMS, no new JS dependencies
