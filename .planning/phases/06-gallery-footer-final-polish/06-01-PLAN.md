| Lightbox overlay | DOM manipulation; prevents accidental page navigation but allows ESC exit |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | Gallery image src | mitigate | Validate image paths exist in file system before rendering; use img alt text for accessibility and content verification |
| T-06-02 | Denial of Service | Lightbox modal overlay | accept | Simple modal with limited interactivity; no computationally expensive operations; low attack surface |
| T-06-03 | Information Disclosure | Footer social links | accept | Social links are intentionally public; no sensitive data exposed |
| T-06-04 | Elevation of Privilege | Body overflow manipulation | mitigate | Only set overflow: hidden when lightbox open; restore immediately on close; no persistent elevation |
