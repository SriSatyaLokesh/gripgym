## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Production URL → Internet | Public website accessed by users; unauthenticated visitors can view all content |
| GitHub Pages → GitHub CDN | Static files served through GitHub's infrastructure; no direct backend |
| GA4 property → Google Analytics | Visitor tracking data sent to Google; PII handling per GA4 ToS |
| Uptime Robot → Production | Monitoring service periodically checks site availability via HTTP requests |
| DNS/Domain → Production URL | Domain records point to GitHub Pages; not configurable until v1.1 custom domain setup |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | robots.txt / sitemap.xml | mitigate | Files created with read-only permissions by GitHub; only owners can modify via git push; no dynamic generation |
| T-07-02 | Information Disclosure | GA4 measurement ID | accept | Measurement ID is public by design (embedded in client-side code); no sensitive data exposed; analytics data encrypted in transit via HTTPS |
| T-07-03 | Information Disclosure | OG preview image | accept | Image is public-facing content; same as gallery images already public; no PII or sensitive data |
| T-07-04 | Denial of Service | Uptime Robot checks | accept | Uptime Robot public monitoring service; rate-limited; no authentication required (monitoring is benefit of service); if rates spike, Uptime Robot absorbs impact |
| T-07-05 | Spoofing | GitHub Pages deployment | mitigate | GitHub Pages provides automatic HTTPS with Let's Encrypt certificates; DNS resolved via GitHub infrastructure; v1.1 custom domain adds CNAME record (requires DNS access control) |
| T-07-06 | Repudiation | Git release tag | mitigate | Git tags are cryptographically signed (recommended but not enforced); all changes tracked in git history; commit author logged; no code signing enforced in v1.0 but feasible for v2.0 |
| T-07-07 | Elevation | GA4 property access | accept | GA4 property linked to Google account; only account owner can modify settings; public measurement ID has no write permissions; data collection is read-only from client perspective |
| T-07-SC | Supply Chain | npm/CDN dependencies | mitigate | WOW.js and Animate.css loaded from CDN with integrity checks (SRI); external dependencies minimal and audited in Phase 1 research; no package manager install in Phase 7 (all Phase 1-6) |

## Acceptance Criteria

- GitHub Pages deployment uses automatic HTTPS; no man-in-the-middle attacks via HTTP
- robots.txt and sitemap.xml are static files; no injection vectors
- GA4 tracking ID is intentionally public; no sensitive credentials embedded
- Uptime Robot monitoring is transparent and logged in site analytics as regular traffic
- No code execution vectors in static HTML/CSS/JS; XSS mitigated by no user input processing
- Release tag v1.0.0 is immutable once pushed; git history provides accountability
